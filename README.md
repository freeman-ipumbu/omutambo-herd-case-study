# Omutambo Herd Operations

A Namibia-first cattle operations workspace for owners and farm managers.

Omutambo brings cattle identity, tags, health, breeding, camps, water points, movements, tasks, costs and evidence into one field-ready operating picture. It is designed around NAD amounts, Southern African dates, intermittent connectivity and clear owner/vet review.

## Product principles

- Make operational state visible.
- Show freshness and offline limits.
- Keep veterinary and financial authority with people.
- Preserve a printable, reviewable record.
- Start with Namibia; design for expansion.

The working demo is private. This repository is a public product case study and contains no livestock records, credentials, photos or deployable private application source.

Built from Windhoek, Namibia.
